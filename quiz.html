🔧 Firebaseの設定が必要です

みんなで一緒に遊ぶには、無料のFirebaseアカウントが必要です。以下の手順で5分で設定できます。

  1. firebase.google.com にアクセスしてGoogleアカウントでログイン
  2. 「コンソールに移動」→「プロジェクトを追加」で新しいプロジェクトを作成
  3. 左メニューの「Realtime Database」→「データベースを作成」→「テストモードで開始」
  4. 画面上部の「プロジェクトの設定」（⚙️）→「マイアプリ」→ウェブアプリ（</>）を追加
  5. 表示された firebaseConfig の値をこのファイルの下記部分に貼り付ける
// quiz.html の FIREBASE CONFIG の部分を以下に書き換え const FIREBASE_CONFIG = { apiKey: "AIza...", // ← ここに貼り付け authDomain: "xxx.firebaseapp.com", databaseURL: "https://xxx-default-rtdb.firebaseio.com", projectId: "xxx", storageBucket: "xxx.appspot.com", messagingSenderId: "000", appId: "1:000:web:xxx" };

※ Realtime Database のルールは「テストモード」のままで大丈夫です（飲み会当日だけ使う場合）。
